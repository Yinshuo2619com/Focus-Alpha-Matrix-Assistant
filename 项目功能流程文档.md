# Focus Alpha Matrix Assistant(阿尔法矩阵助手) - 完整功能流程文档

## 项目概述
Focus Alpha Matrix Assistant是一个基于前后端分离架构的在线教育平台，目前实现了用户认证功能（注册、登录、退出登录），为后续扩展更多教育功能奠定了基础。

---

## 技术架构

### 前端技术栈
- **框架**: Vue 3 + TypeScript + Vite
- **UI 组件库**: Element Plus
- **状态管理**: Pinia
- **路由**: Vue Router
- **HTTP 客户端**: Axios

### 后端技术栈
- **框架**: Spring Boot 4.0.4
- **数据库**: MySQL
- **认证**: JWT (JSON Web Token) + Spring Security
- **密码加密**: BCrypt
- **构建工具**: Maven

## 核心功能流程

### 1. 用户注册流程

#### 流程说明
1. 用户访问注册页面
2. 填写用户名、密码、确认密码
3. 前端进行表单验证（用户名 3-20 字符，密码 6-20 字符，两次密码一致）
4. 发送 POST 请求到 `/api/auth/register`
5. 后端检查用户名是否已存在
6. 使用 BCrypt 加密密码
7. 插入新用户记录到数据库
8. 返回注册成功消息
9. 前端跳转到登录页

#### 前端代码逻辑 (Register.vue)

```typescript

const registerRules = {

  ],
  password: [
    { required: true, message: '请输入密码' },
    { min: 6, max: 20, message: '密码长度为6-20个字符' }
```

#### 后端代码逻辑 (UserServiceImpl.java)

```java
public void register(LoginRequest registerRequest) {
    // 1. 检查用户名是否已存在
    String checkSql = "SELECT COUNT(*) FROM user WHERE username = ?";
    Integer count = jdbcTemplate.queryForObject(checkSql, Integer.class, 
        registerRequest.getUsername());
    
    if (count != null && count > 0) {
        throw new RuntimeException("用户名已存在");
    }

    // 2. 使用 BCrypt 加密密码
    String encodedPassword = passwordEncoder.encode(registerRequest.getPassword());

    // 3. 插入新用户
    String insertSql = "INSERT INTO user (username, password, nickname, email, status, created_at, updated_at) 
                        VALUES (?, ?, ?, ?, 1, NOW(), NOW())";
    jdbcTemplate.update(insertSql, 
        registerRequest.getUsername(), 
        encodedPassword,
        registerRequest.getUsername(),
        registerRequest.getUsername() + "@example.com"
    );
}
```

### 2. 用户登录流程

#### 流程说明
1. 用户访问登录页面
2. 填写用户名和密码
3. 前端进行表单验证（用户名和密码必填）
4. 发送 POST 请求到 `/api/auth/login`
5. 后端查询用户是否存在
6. 使用 BCrypt 验证密码
7. 生成 JWT Token（有效期 24 小时）
8. 返回 Token 和用户信息
9. 前端保存 Token 到 localStorage
10. 跳转到主页

#### 前端代码逻辑 (Login.vue + user.ts)

```typescript
// Login.vue - 登录处理
const handleLogin = async () => {

// user.ts - 状态管理
const login = async (username: string, password: string) => {
  const res = await request.post('/auth/login', { username, password })
  
  // 检查响应并保存 Token
  if (res.code === 200 && res.data && res.data.token) {
    token.value = res.data.token
    localStorage.setItem('token', res.data.token)
  }
  return res
}
```

#### 后端代码逻辑 (UserServiceImpl.java)

```java
public Map<String, Object> login(LoginRequest loginRequest) {
    // 1. 查询用户
    String sql = "SELECT * FROM user WHERE username = ?";
    User user = jdbcTemplate.queryForObject(sql, (rs, rowNum) -> {
        User u = new User();
        u.setId(rs.getLong("id"));
        u.setUsername(rs.getString("username"));
        u.setPassword(rs.getString("password"));
        u.setNickname(rs.getString("nickname"));
        u.setEmail(rs.getString("email"));
        u.setStatus(rs.getInt("status"));
        return u;
    }, loginRequest.getUsername());

    if (user == null) {
        throw new RuntimeException("用户不存在");
    }

    // 2. 验证密码 (BCrypt)
    if (!passwordEncoder.matches(loginRequest.getPassword(), user.getPassword())) {
        throw new RuntimeException("密码错误");
    }

    // 3. 生成 JWT Token
    String token = jwtUtil.generateToken(user.getUsername());

    // 4. 返回结果
    Map<String, Object> result = new HashMap<>();
    result.put("token", token);
    result.put("userId", user.getId());
    result.put("username", user.getUsername());
    result.put("nickname", user.getNickname());

    return result;
}
```

### 3. JWT 认证流程

#### 流程说明
1. 用户发起需要认证的请求
2. Axios 请求拦截器在请求头中添加 `Authorization: Bearer <token>`
3. Spring Security 检查请求路径
   - `/api/auth/**` 路径放行
   - 其他路径需要认证
4. 后端验证 JWT Token 有效性
5. 有效则继续处理业务逻辑
6. 无效则返回 401 错误
7. 前端响应拦截器处理 401 错误，清除 Token 并跳转登录页

#### 前端认证拦截器 (request.ts)

```typescript
// 请求拦截器 - 添加 Token
request.interceptors.request.use((config) => {
  const token = localStorage.getItem('token')
  if (token) {
    config.headers.Authorization = `Bearer ${token}`
  }
  return config
})

// 响应拦截器 - 处理认证失败
request.interceptors.response.use(
  (response) => response.data,
  (error) => {
    if (error.response?.status === 401) {
      localStorage.removeItem('token')
      router.push('/login')
      ElMessage.error('登录过期，请重新登录')
    }
    return Promise.reject(error)
  }
)
```

#### 后端安全配置 (SecurityConfig.java)

```java
@Configuration
@EnableWebSecurity
public class SecurityConfig {
    
    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
        http
            .csrf(csrf -> csrf.disable())  // 禁用 CSRF
            .cors(cors -> cors.configurationSource(corsConfigurationSource()))
            .sessionManagement(session -> 
                session.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/api/auth/**").permitAll()  // 认证接口放行
                .anyRequest().authenticated()  // 其他接口需要认证
            );
        return http.build();
    }
}
```

#### JWT 工具类 (JwtUtil.java)

```java
@Component
public class JwtUtil {
    @Value("${jwt.secret}")
    private String secret;

    @Value("${jwt.expiration}")
    private long expiration;  // 86400000 ms = 24 小时

    // 生成 Token
    public String generateToken(String username) {
        return Jwts.builder()
                .subject(username)
                .issuedAt(new Date())
                .expiration(new Date(System.currentTimeMillis() + expiration))
                .signWith(getSigningKey())
                .compact();
    }

    // 验证 Token
    public boolean validateToken(String token) {
        try {
            Jwts.parser()
                .verifyWith(getSigningKey())
                .build()
                .parseSignedClaims(token);
            return true;
        } catch (JwtException e) {
            return false;
        }
    }
}
```

### 4. 路由保护流程

#### 流程说明
1. 用户访问页面
2. Vue Router 路由守卫拦截
3. 检查路由元信息 `requiresAuth`
4. 如果需要认证：
   - 检查 localStorage 中是否有 Token
   - 有 Token 则继续访问
   - 无 Token 则重定向到登录页
5. 如果不需要认证，直接访问

#### 路由配置 (router/index.ts)

```typescript
const routes = [
  {
    path: '/login',
    name: 'Login',
    component: () => import('@/views/Login.vue')
  },
  {
    path: '/register',
    name: 'Register',
    component: () => import('@/views/Register.vue')
  },
  {
    path: '/',
    name: 'Home',
    component: () => import('@/views/Home.vue'),
    meta: { requiresAuth: true }  // 需要认证
  }
]

// 路由守卫
router.beforeEach((to, _from, next) => {
  const token = localStorage.getItem('token')
  
  if (to.meta.requiresAuth && !token) {
    next('/login')  // 未登录，重定向到登录页
  } else {
    next()  // 已登录或不需要认证，继续
  }
})
```

4. 清除 localStorage 中的 token
5. 显示退出成功消息
6. 跳转到登录页

## 安全特性

### 1. 密码安全
- 使用 BCrypt 算法加密存储密码
- 密码明文永不存储到数据库
- 登录时使用 BCrypt.matches() 验证密码

### 2. JWT 认证
- 无状态认证，不需要服务器存储会话信息
- Token 有效期 24 小时
- 使用 HMAC-SHA256 算法签名
- 密钥长度满足安全要求（256 位以上）

### 3. CORS 配置
- 仅允许前端域名 `http://localhost:5173` 访问
- 支持 GET、POST、PUT、DELETE、OPTIONS 方法
- 允许携带凭证（Cookie）

### 4. CSRF 保护
- 已禁用（因为使用 JWT 无状态认证）
- JWT Token 本身具有防 CSRF 能力

### 5. 路由保护
- 前端路由守卫检查用户登录状态
- 未登录用户无法访问需要认证的页面
- 401 错误自动清除 Token 并跳转登录页

### 6. 会话管理
- 使用无状态会话（STATELESS）
- 不依赖服务器端会话存储
- 适合分布式部署
